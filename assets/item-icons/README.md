# 商品アイコン（書き出し）

`src/game/data/icons.ts` の 16×16 ドット絵を `node scripts/export-icons.mjs` で書き出したもの。背景は透過。

- `png-16/` 原寸、`png-128/` 8 倍、`png-512/` 32 倍（最近傍拡大なので輪郭はシャープ）
- `svg/` ベクター（任意のサイズで使える）
- `sheet-128.png` 24 種を 6×4 に並べたもの
